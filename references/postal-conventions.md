# Postal convention verification

Before generating a formal country-specific issue, use current official postal-operator sources to verify the country label and the exact face-value convention. Do not infer postal wording from currency alone.

1. Search the official postal operator for a current comparable stamp product or current issuance page.
2. Match the country name, denomination format, and service class shown on the stamp or in issuance details.
3. Match the symbol or service indicator, symbol placement, decimal separator, local country-name form, numeral style, relative type size, and border placement. Do not assume every country prints a currency symbol.
4. Use the verified convention in the image prompt. If official practice is unclear, use a clearly labeled concept treatment rather than inventing a supposedly official format.

## Location fallback

Determine country in this order: embedded GPS/provenance, explicit user context, then a clearly identifiable landmark verified with reliable sources. Visual atmosphere alone is not location evidence. When none is available, issue the concept as United States and use the current standard U.S. domestic convention; keep capture location/date marked unavailable.

## United States

For a standard U.S. domestic one-ounce First-Class Mail issue, use `USA FOREVER` on the stamp rather than a fixed dollar face value. USPS explains that Forever stamps retain the current one-ounce First-Class Mail value when rates change. Verify the current wording before rendering through [USPS First-Class Mail](https://www.usps.com/ship/first-class-mail.htm) and a current [USPS stamp product](https://store.usps.com/store/product/us-flag-2026-stamps-S_130104).

Use a numerical U.S. denomination only when the requested issue is explicitly a non-Forever denomination and official USPS practice for that product supports it.
