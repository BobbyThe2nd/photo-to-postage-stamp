# Style lock

Use the generated style-selector board as a mandatory reference whenever the user has selected a numbered option.

- Provide the selector board with the source photo to the image generator.
- Name the selected tile or tiles explicitly and preserve their visual language: palette, flatness, line density, texture, and degree of simplification.
- Do not reinterpret a selected tile based on the source photo. The preview is the authority.
- For `SCHEME_MINI_ICON`, use 3–5 large geometric color shapes, a flat two-dimensional cat/object silhouette, thick clean outlines, and no fur rendering, floorboard texture, or realistic lighting.
- For a multi-style pane, state one style lock for each stamp and keep its background visible around the stamp block.
